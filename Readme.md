# Ecomix - Sistema Web de Ventas

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://python.org)
[![Django](https://img.shields.io/badge/Django-4.2-green.svg)](https://djangoproject.com)
[![Bootstrap](https://img.shields.io/badge/Bootstrap-5.0-purple.svg)](https://getbootstrap.com)

Sistema web de punto de venta desarrollado para **Ecomix**, comercio local especializado en tecnología y artículos de oficina. Incluye gestión de inventario, procesamiento de ventas rápidas y sistema de reportes.

## Características Principales

- **Punto de Venta Rápido** - Procesa transacciones en menos de 30 segundos
- **Gestión de Inventario** - Control de stock con alertas en tiempo real
- **Sistema de Roles** - Administrador, Supervisor y Cajero
- **Reportes Automatizados** - Ventas, inventario y métricas de negocio
- **Seguridad OWASP** - Protección contra vulnerabilidades web
- **Interfaz Responsive** - Compatible con dispositivos móviles

## Stack Tecnológico

### Backend
- **Framework**: Django 4.2 + Django REST Framework
- **Base de datos**: SQLite (Desarrollo) / PostgreSQL (Producción)
- **Autenticación**: JWT Tokens
- **API**: RESTful API

### Frontend
- **Framework**: Bootstrap 5.3
- **Lenguaje**: JavaScript ES6+
- **Estilos**: CSS3 personalizado
- **Iconos**: Bootstrap Icons

### Desarrollo
- **Control de versiones**: Git + GitHub
- **Metodología**: Scrum
- **Calidad**: ISO/IEC 25010
